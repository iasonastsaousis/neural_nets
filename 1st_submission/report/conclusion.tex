\section{Conclusion}
In this experiment, 1-NN achieved 17.55\%, 3-NN 17.48\% and NCC 10.04\%.
The k-NN results are very close: the difference is only seven correct
predictions, or 0.07 percentage points. Without further statistical
analysis, this does not establish general superiority of 1-NN.
Both k-NN models outperformed NCC in this feature space, while NCC had
much lower prediction cost.

Distinguishing the algorithm from its implementation was important.
The original code made the classification rules explicit; the optimized
version used matrix operations, partial neighbor selection and a shared
search for both values of $k$. Agreement with the reference was checked
before using the final results. The full shared k-NN search completed in
about 10.3 s on CPU, without reducing the training set or applying PCA.
The modest accuracy illustrates that faster execution does not add
semantic information to raw RGB features.
